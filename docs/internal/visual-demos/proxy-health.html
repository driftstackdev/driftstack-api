UDP ASSOCIATE The full-stack gate SOCKS5 UDP relay is what carries everything below. Probed with a real ASSOCIATE handshake + echo round-trip — not just the advertised auth method. No UDP = TCP-only exit.
QUIC / HTTP-3 Protocol coherence Real iPhones speak h3 to half the web. Through a UDP-capable exit, sessions negotiate h3 natively; on a TCP-only exit they fall back to h2 — functional, but a flat-h2 profile is a quieter, older-looking client. Prefer full-stack exits for high-trust targets.
WebRTC Media + ICE posture STUN/TURN need UDP through the same exit, or calls and webcam checks degrade to TURN-over-TCP. The probe walks a real ICE gather through the relay and confirms the reflexive address matches the exit geo.

Checks run from the fleet, through each proxy, against neutral endpoints — reachability, round-trip latency, exit-IP geolocation, and a capability probe per protocol (TCP CONNECT · UDP ASSOCIATE echo · h3 handshake · ICE gather). Sessions never launch through an unreachable exit; geo drift warns before a profile's story stops matching its network; capability results are re-probed daily and greyed (?) while an exit is unreachable.
