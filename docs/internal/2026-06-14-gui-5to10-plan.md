# GUI 5→10 plan — founder directive round 2 (2026-06-14)

Founder re-rated the GUI **5/10** and gave **greenlight for major frontend refactors** ("you got
greenlight for major refactors on frontend if you come up with good ideas… hopefully you can make it a
lot better"). Goal: a **perfect, clean, feature-complete 10/10 GUI**, frontend-first. This plan turns
the founder's specific asks + my own ideas into an ordered build. Companion to
`2026-06-14-gui-console-build-plan.md` (Console slices) + `2026-06-14-gui-greatness-backlog.md` (tiers).

## Founder's explicit asks (round 2) — verbatim → action

1. **"Automate (AI chat, recipes) should be above Browse."** → Sidebar ALREADY orders Automate above
   Browse (rebuild #5 shipped it). Remaining intent = make Automate feel _primary_: (a) keep the order,
   (b) consider Automate/AI as a more prominent landing or a Command-Center that leads with it. ✅ order
   done; prominence folded into G4 below.
2. **"UDP can be made more professional — Has WebRTC, Has QUIC, etc."** → replace the single "UDP" badge
   with an honest **protocol-capability breakdown** (WebRTC / QUIC / HTTP-2) derived from the probe. → **G1, shipping first.**
3. **"the grid has random images of a browser."** → the device-frame `MiniPage` thumbnails render a
   stylized fake webpage → reads as random/unprofessional. Replace with a clean, real signal: last
   live-session screenshot if we have one, else a tasteful identity card (archetype glyph + accent, the
   profile's device + locale) — NOT a fake page. → **G2.**
4. **"missing tags."** → a per-profile **tag** system: add/remove tags, color them, filter the grid by
   tag (alongside folders). Local store like folders/probe-cache. → **G3.**
5. **"folder creation on profile selection on grid."** → create / rename / assign folders **inline from
   the grid** (a "+ New folder" affordance + drag/assign), not just an implicit list. → **G3.**
6. **"so many more features could be made here!" / "make it a lot better."** → the elevation backlog
   (Command Center, bulk actions, conversation history, live streaming, export/import) → **G4+.**

## Ordered build (frontend-first; each = gate-green slice + batched Tauri rebuild)

- **G1 — Proxy protocol capabilities (professional).** Shared `proxyCapabilities()` helper + capability
  chips (WebRTC ✓/⤵, QUIC ✓/⤵, HTTP/2 ✓) derived honestly from the SOCKS5 probe (udp*associate gates
  the UDP-borne protocols). Use in BOTH ProxiesView + ProfilesView so the proxy story is consistent.
  *(This slice.)\_
- **G2 — Kill the fake grid thumbnails.** Replace `MiniPage` with: real last-session screenshot when
  available; else a clean identity card (archetype mark + accent wash + device/locale chips). No
  invented webpage. Likely a focused refactor of the ProfilesView card visual.
- **G3 — Tags + inline folder management.** Tag store (create/assign/color/remove) + a tag filter rail;
  inline folder create/rename/assign from the grid (and on the profile card). Folders + tags become the
  two orthogonal organizers. Drag-to-folder is a stretch within this slice.
- **G4 — Command Center landing + Automate prominence.** A new default home composing KPI tiles +
  session-health + activity + a prominent "Ask AI / run a recipe" entry, so Automate leads. Pushes
  Browse to a deliberate choice, not the forced first screen.
- **G5 — Profile create/edit flow polish.** Guided create (identity → proxy bind+test → launch),
  archetype/fingerprint surfacing, consistency badge.
- **G6 — Power tooling.** Full bulk-action bar over selection, action-grade ⌘K (live verbs),
  saved/smart views, keyboard-first list nav, optimistic UI + undo.
- **G7 — AI depth.** Live SSE transcript streaming, conversation-history sidebar, AI cost/budget panel,
  hand-off-to-AI from a session.
- **G8 — Final 10/10 polish pass.** Empty-states with personality, transitions/micro-interactions,
  cheatsheet, a11y sweep, consistency audit across every view.

## Constraints / method

- Frontend-first per founder. GUI visuals aren't self-verifiable (no render) → gate via gui-jsdom +
  founder opening a Tauri rebuild; batch a rebuild after each meaningful group.
- Major refactors are greenlit — but keep each slice gate-green + tested + content-parity pins updated
  in-commit; push at a calm load window (box oscillates 6↔72).
- Don't auto-do gated items (real agent execution = Agent-1; archetype cutover = canvas-gated).
